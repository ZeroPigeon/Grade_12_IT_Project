# Grade 12 IT PAT

## Overview

This was my project submission for grade 12 PAT. I challenged myself to push Delphi to its limits and to see what I can do with a little bit of creativity. It simulates the process of delivering packages like a courier service, it simulates the admin control panel, the driver control panel and the customer ordering screens as well as tracking services on a specified screen.

## Technologies Used
 Delphi

## How It Works

When the application first starts up, you'll be presented with a login screen, there is also the option of creating a new account. You will only be able to create a client account using this screen as to avoid unauthorized access to sensitive parts of the application. Admin and driver accounts are already created and stored within the database, to login to the application without having to go create a new account inside the database you can use:

You can create specific user accounts in the admin tab for new driver or admin accounts. You can also view the position of each car within the map screen, available through the admin control panel. The driver dashboard will show the next package and the destination. The client screen allows a user to order the package and then view the progress of the delivery through the map screen or leave a review on their experience.
